# Wonnderay для Android

VPN-клиент на VLESS/Xray. Подписки, серверы, честный пинг — без лишнего.

## О приложении

- **Подписки.** Добавляются ссылкой, обновляются сами — у каждой свой интервал,
  а не один общий на всё приложение: панель, которая тасует серверы каждый час,
  и панель, которая меняется дважды в год, — разные случаи.
- **Серверы.** Список с пингом, избранное, поиск и сортировка. Пинг меряется
  через сам туннель, поэтому показывает то, что вы почувствуете, а не время до
  ближайшего маршрутизатора.
- **Выбор лучшего сервера** одной кнопкой — по результатам замера, а не по
  порядку в списке.
- **Какие приложения через VPN.** Список с иконками: можно пустить в туннель
  только нужное или наоборот исключить.
- **Kill switch.** Если ядро упадёт, трафик блокируется, а не уходит напрямую
  мимо VPN.
- **Протоколы:** VLESS поверх TCP / WS / gRPC / XHTTP, TLS и Reality.
- Русский и английский, тёмная тема, Android 5.0 и новее.

Приложение ничего не имитирует: «Подключено» загорается только когда ядро
живо и туннель принят системой, а пинг показывает измеренное значение либо
честный прочерк.

## Скачать

Актуальная версия — на вкладке [Releases](../../releases/latest).

| Файл | Для кого |
| --- | --- |
| `wonnderay-<версия>-arm64-v8a.apk` | Почти все современные телефоны |
| `wonnderay-<версия>-armeabi-v7a.apk` | Старые 32-битные устройства |
| `wonnderay-<версия>-x86_64.apk` | Эмуляторы и планшеты на x86 |
| `wonnderay-<версия>-universal.apk` | Подходит везде, весит больше |

Если не уверены, какой брать — берите `universal`. Приложение обновляет себя
само и качает именно его.

Android спросит разрешение на установку из неизвестных источников — это
обычное дело для APK не из Play Store.
