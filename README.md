## Что это

Wonnderay подключает телефон к **вашему собственному** серверу и пропускает
через него трафик. Своих серверов у приложения нет и не продаётся ничего: вы
даёте ему ссылку `vless://` или адрес подписки, выданный панелью, а оно делает
остальное — хранит список, меряет задержку, поднимает туннель и следит, чтобы
трафик действительно пошёл туда, куда обещано.

Внутри работает то же самое ядро Xray, на котором стоит сервер. Всё вокруг него
— интерфейс и управление системой.

## Возможности

| Что умеет | Подробности |
| --- | --- |
| **Подписки** | Добавляются ссылкой и обновляются сами, **у каждой свой интервал**. Панель, которая тасует серверы каждый час, и панель, которая меняется дважды в год, — разные случаи, и один общий интервал в настройках не мог выразить ни один из них. Приложение предупреждает, когда подписка подходит к концу — пока телефон лежит выключенным, узнать об этом больше неоткуда. |
| **Серверы** | Список с пингом, избранное, поиск и сортировка. Пинг меряется запросом **через сам сервер**, а не рукопожатием до его порта: рукопожатие одинаково успешно проходит и с мёртвым сервером, и с неверным UUID, и с истёкшей подпиской. |
| **Лучший сервер** | Одна кнопка: гасит туннель, меряет весь список и поднимается на победителе. Туннель гасится не для красоты — через поднятый туннель любая цифра описывает его, а не серверы. |
| **Приложения через VPN** | Список с иконками: пустить в туннель только нужное или, наоборот, исключить. |
| **Kill switch** | Упало ядро — трафик блокируется, а не уходит мимо VPN в открытую. |
| **Локальный прокси** | SOCKS5 и HTTP на самом телефоне, при желании — на всю локальную сеть, чтобы раздать туннель телевизору или консоли. Пароля они не спрашивают, и приложение говорит об этом прямым текстом, а не мелким шрифтом. |
| **Маршрутизация** | Локальная сеть, домены и адреса мимо туннеля, `.ru` и `.рф` напрямую. |
| **Оформление** | Чёрный OLED-фон, обои из галереи, акцент, взятый прямо из картинки. Русский, английский и муринский. |
| **Часы** | Есть сборка для Wear OS — серверы уезжают на неё с телефона, отдельный интернет часам не нужен. Лежит в релизах здесь же. |

## Скачать

Актуальная версия — на вкладке **[Releases](../../releases/latest)**.

| Файл | Для кого |
| --- | --- |
| `wonnderay-<версия>-universal.apk` | **Если не уверены — берите этот.** Подходит везде, весит больше |
| `wonnderay-<версия>-arm64-v8a.apk` | Почти все современные телефоны |
| `wonnderay-<версия>-armeabi-v7a.apk` | Старые 32-битные устройства |
| `wonnderay-<версия>-x86_64.apk` | Эмуляторы и планшеты на x86 |

Приложение обновляет себя само и качает именно `universal`. Android спросит
разрешение на установку из неизвестных источников — обычное дело для APK не из
Play Store.
